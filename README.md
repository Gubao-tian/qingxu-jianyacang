# 🌿 情绪减压舱

> 把烦心事放进减压舱，它会接住你、陪你理清，再给你一份马上能做的解忧方案。

一个**纯前端、零依赖、数据本地存储**的情绪陪伴小工具。写下你的烦心事，它会自动识别情绪与场景，生成「共情 → 拆解 → 行动」三段的解忧方案，并支持一键生成可分享的卡片与长图。

## ✨ 功能

- **情绪识别**：自动识别 9 种情绪（焦虑、疲惫、委屈、迷茫、生气、孤独、内耗、低落、担忧）
- **场景分类**：8 大场景（职场内耗、考试焦虑、亲子/家庭、感情困扰、人际社交、自我内耗、健康焦虑、经济压力）
- **解忧方案**：共情（先接住你）+ 拆解（能改变的 vs 控制不了的）+ 行动（今天就能做的小事）
- **解忧卡片**：竖版 3:4 卡片，4 种配色，适合发朋友圈/小红书
- **回信长图**：把完整回信生成长图保存分享
- **每日一句**：按日期轮换的治愈语录
- **心情打卡 + 晴雨表**：6 种心情打卡，自动生成 14 天情绪趋势图
- **语音输入**：说话即可倾诉（Web Speech API）
- **4-7-8 呼吸**：一分钟降噪练习
- **本地存档**：心事存进减压舱，仅本机可见

## 🔒 隐私

所有内容只在你的浏览器本地运行，**不上传任何服务器**。数据存储在 `localStorage` 中，换设备不会同步。

## 🚀 使用

直接用浏览器打开 `index.html` 即可，无需任何构建或依赖。

```bash
# 或者本地起一个服务
python -m http.server 8000
# 打开 http://localhost:8000
```

> 语音输入需要浏览器授权麦克风，建议通过 `localhost` 或 `https` 访问。
